# BMS Intercom

Вызывная панель в Home Assistant: входящий вызов → поп-ап с видео и
**полным двусторонним звуком** → **Ответить / Открыть / Сбросить**, как телефон.

- Поп-ап встроен — без browser_mod и правки дашборда.
- Видео и входящий звук — через встроенный go2rtc.
- Микрофон → панель — напрямую через **ISAPI** (go2rtc-аддон и `configuration.yaml` не нужны).
- Просмотр живого видео без звонка (переключатель «Просмотр»).
- **Демо-режим** для настройки без оборудования.

После установки: **Настройки → Устройства и службы → Добавить интеграцию → BMS Intercom**
(нужны только IP / логин / пароль панели).
